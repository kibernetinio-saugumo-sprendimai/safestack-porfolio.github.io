# SafeStack Portfolio

Official public portfolio and verifiable systems showcase portal for the [SafeStack](https://github.com/kibernetinio-saugumo-sprendimai) ecosystem.

Live URL: **https://safestack.engineering**

## Scope & Capabilities

This portal presents all verified open-source and public repositories across the SafeStack organisation, strictly excluding internal and private modules.

- **Verified Public Systems:** Twenty-two open-source repositories spanning trust canons, runtime operating layers, intelligence tooling, and ecosystem meta assets.
- **Dynamic Category Filtering:** Real-time client-side exploration across architectural domains (Trust & Registry, Runtime & Infrastructure, Intelligence & Automation, Web & Publishing, Ecosystem & Meta).
- **Cryptographic Grounding:** Identity anchored by Ed25519 `project-019` public key, verifiable via `safestack-project-public-keys`.
- **Zero Framework Bloat:** Self-contained vanilla HTML5, CSS3, and minimal zero-dependency JavaScript.
